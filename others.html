3. 下載 App

本網站已支援 PWA（漸進式網頁應用程式），可安裝到任何裝置的主畫面，離線也能瀏覽學過的頁面。

📱

Android

直接從瀏覽器安裝 PWA，或使用 PWA Builder 打包為 .apk 安裝檔。

  1. 用 Chrome 開啟本網站
  2. 點右上角 ⋮ 選單
  3. 選「新增至主畫面」
  4. 確認後即完成安裝
用 PWA Builder 產生 APK

進入 PWA Builder → 點「Package for stores」→ 選「Android」→ 下載 .apk。

🍎

iPhone / iPad

iOS 透過 Safari 的「加入主畫面」功能安裝，體驗近似原生 App。

  1. 用 Safari 開啟本網站
  2. 點底部 分享 按鈕 ⬆
  3. 向下捲動，選「加入主畫面」
  4. 點右上角「新增」確認

⚠ iOS 只有 Safari 支援加入主畫面，Chrome 和 Firefox 不適用。

🖥

電腦（Chrome / Edge）

桌機安裝後以獨立視窗開啟，沒有瀏覽器工具列。

  1. 用 Chrome 或 Edge 開啟
  2. 點網址列右側的 安裝 圖示 ⊕
  3. 或從選單選「安裝 AC Coding…」
✈️

5. 問卷調查

感謝你使用 AC 程式設計學習平台！為了提升服務品質，我們很希望聽聽你的意見。

此問卷涵蓋以下項目：

  • 使用體驗：對各功能區塊的滿意度
  • 內容需求：希望增加的課程和功能
  • 學習成效：平台對你的幫助程度
  • 改進建議：開放式意見和建議

重要提醒： 你的回應完全匿名且保密。我們只用於改進服務，絕不會與第三方分享。
